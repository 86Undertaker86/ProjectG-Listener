ForzaListener — запис телеметрії Forza Horizon 6
=================================================

1. Запустіть ForzaListener.exe (тека ForzaListener має лишатися цілою: exe не працює
   без теки _internal поруч).
   - Якщо Windows покаже «Windows захистив ваш ПК» — натисніть «Докладніше» →
     «Все одно запустити» (програма не має платного цифрового підпису).
   - Якщо брандмауер спитає про доступ до мережі — дозвольте (приватні мережі).

2. У вікні видно IP цього комп'ютера і порт (за замовчуванням 49152).
   У грі: налаштування → Data Out → увімкнути, IP = цей IP, порт = цей порт.

3. «Змінити…» — вибрати теку, куди зберігати записи (за замовчуванням
   Документи\ForzaTelemetry). «Відкрити теку» — подивитися записи.

4. «Старт» — і їдьте. Запис іде лише під час заїзду; на кожну машину окремий файл .bin.
   «Стоп» або закриття вікна — дописує все на диск.

5. Відкрийте калькулятор на сайті https://projectg.g-garage.workers.dev/calculator
   і завантажте туди файл .bin із теки записів. Якщо щось пішло не так, у тій самій
   теці є listener_log.txt — журнал слухача.
